FAQ

Pertanyaan umum

Apakah website lama saya tetap bisa dipakai selama proses upgrade?

Ya, website lama tetap online selama proses upgrade. Kami bekerja di environment staging terpisah. Setelah website baru siap dan Anda approve, baru kami migrasi ke domain utama — minim downtime.

Berapa lama proses upgrade?

Standar 7-14 hari kerja untuk website bank 10-15 halaman. Untuk fitur custom seperti simulasi kredit atau integrasi API banking, bisa 3-4 minggu. Timeline detail diberikan setelah diskusi.

Bagaimana dengan konten website lama saya?

Kami migrasi semua konten yang masih relevan (profil, produk, berita, galeri) ke website baru. Tim kami juga bantu rewrite copy agar lebih menarik dan SEO-friendly.

Apakah tim bank kami bisa update konten sendiri?

Ya. Semua paket sudah termasuk CMS user-friendly. Tim marketing/humas Anda bisa update berita, suku bunga, kurs, promo sendiri. Kami kasih training gratis 2 jam via Zoom.

Apakah aman untuk institusi keuangan?

Sangat aman. Standar tinggi: SSL (HTTPS), firewall, proteksi DDOS, backup harian, anti-spam, dan proteksi konten. Kami comply dengan standar OJK untuk website perbankan.

Bagaimana sistem pembayarannya?

DP 50% di awal, pelunasan 50% setelah website live. Kami bisa terbitkan invoice resmi dengan NPWP perusahaan untuk administrasi bank. Pembayaran via transfer bank.

Apakah ada garansi?

Garansi 100% uang kembali jika dalam 7 hari pertama setelah mockup dikirim Anda merasa tidak cocok. Setelah live, kami berikan garansi 3 bulan bug fixing gratis + support 24/7.
