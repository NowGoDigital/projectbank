FAQ

Pertanyaan umum

Jawaban untuk pertanyaan yang sering ditanyakan oleh manajemen bank.

Berapa lama proses pembuatan website bank?

Untuk website bank standar (10-15 halaman) biasanya selesai dalam 7-14 hari kerja. Untuk fitur tambahan seperti simulasi kredit, form pengajuan online, atau integrasi API banking, timeline bisa 3-4 minggu.

Apakah tim bank kami bisa mengupdate konten sendiri?

Ya, pasti. Semua paket sudah termasuk CMS (Content Management System) yang user-friendly. Tim marketing atau humas bank Anda bisa update berita, suku bunga, kurs, promo sendiri. Kami juga kasih training gratis 2 jam via Zoom.

Apakah website akan muncul di Google?

Ya, website akan ter-index di Google. Kami sudah optimasi SEO on-page (meta tag, struktur heading, sitemap, schema markup). Untuk ranking halaman 1 Google pada kata kunci kompetitif, kami juga menawarkan jasa SEO bulanan sebagai add-on.

Apakah website aman untuk institusi keuangan?

Sangat aman. Kami menerapkan standar keamanan tinggi: SSL certificate (HTTPS), firewall, proteksi DDOS, backup harian, anti-spam, dan proteksi konten dari copy-paste. Kami juga comply dengan standar OJK untuk website perbankan.

Bagaimana jika setelah 1-2 tahun domain/hosting habis?

Kami akan ingatkan 1 bulan sebelum habis. Biaya perpanjangan domain + hosting sekitar Rp 1.5 - 2.5 Juta/tahun (tergantung paket). Anda juga bisa migrasi ke penyedia hosting lain karena seluruh source code kami serahkan 100%.

Apakah ada garansi?

Garansi 100% uang kembali jika dalam 7 hari pertama setelah desain mockup dikirim Anda merasa tidak cocok (sebelum development dimulai). Setelah website live, kami berikan garansi 3 bulan untuk bug fixing gratis.

Bagaimana sistem pembayarannya?

Sistem kami fleksibel untuk institusi: DP 50% di awal, pelunasan 50% setelah website live. Kami bisa terbitkan invoice resmi dengan NPWP perusahaan untuk kebutuhan administrasi bank Anda. Pembayaran via transfer bank.

Apakah bisa request fitur khusus seperti simulasi kredit?

Tentu bisa. Kami bisa bangun fitur custom seperti: simulasi KPR/KUR, kalkulator deposito, form pengajuan kredit online, form buka rekening digital, tabel kurs real-time, login internet banking (iframe), dan integrasi dengan core banking system Anda.
